# Spare (سبير)

تطبيق ويب مبني بـ Next.js (App Router) لخدمة دليل محلات الميكانيك في الأردن، مع واجهة عربية RTL ونظام ثيمات متعدد.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## أوامر أساسية

```bash
npm run lint
npm run build
```

## ملاحظات تقنية

- الواجهة عربية بالكامل مع `lang="ar"` و `dir="rtl"`.
- النظام يدعم 4 ثيمات محفوظة في `localStorage`.
- يعتمد التصميم على Tailwind CSS ومكونات UI محلية خفيفة.
